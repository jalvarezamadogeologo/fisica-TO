¿Qué es esta guía?

Esta es una guía de estudio autoinstruccional diseñada para que prepares el curso de Física (CBA0210) de forma activa. No se trata solo de leer teoría: en cada tema encontrarás un objetivo claro, un ejemplo resuelto, ejercicios guiados y autónomos, y una autoevaluación de 3 preguntas con feedback inmediato.

El progreso se guarda automáticamente en tu navegador. Puedes cerrar y volver después: tus temas marcados como "dominado" se conservarán.

Cómo usar cada tema (en este orden)

  1. Lee el objetivo de aprendizaje: qué sabrás hacer al terminar.
  2. Responde la pregunta de activación para conectar con lo que ya sabes.
  3. Estudia el concepto clave y la fórmula.
  4. Observa el ejemplo modelo paso a paso.
  5. Haz la práctica guiada (usa las pistas si te atascas).
  6. Intenta la práctica autónoma sin ayuda.
  7. Rinde la autoevaluación de 3 preguntas y revisa el feedback.
  8. Lee el caso clínico y los errores frecuentes.
  9. Si lo dominas, márcalo como ✓ Dominado en la lista de verificación.

Test diagnóstico inicial (10 preguntas)

Responde lo que sepas. No afecta tu nota; sirve para saber por dónde empezar y qué repasar con prioridad.

Unidad 3 — Circuitos y Fluidos
